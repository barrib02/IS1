# READ ME
Estamos desarrollando una página web que permite conectar a personas de todo el mundo a través de sus gustos en películas, series, libros y videojuegos. Cada usuario en su cuenta podrá tener un seguimiento de sus gustos y podrá valorar estos. Además, esta opinión será compartida en la página web, permitiendo que otros usuarios puedan leerla. Tenemos la intención de crear una comunidad en la que se pueda recomendar y recibir recomendaciones, tanto de otros usuarios como de la propia aplicación, que tendá en cuenta lo visto y lo valorado.

## 2. Características:
### Gestión de colecciones
- Añadir contenido a la biblioteca personal
- Crear listas personalizadas
- Marcar contenido como "Pendiente", "En progreso", etc.
 
### Valoraciones y reseñas
- Sistema de puntuación
- Reseñas escritas
- Comentarios en reseñas
 
### Social
- Perfiles de usuario
- Seguimiento entre usuarios
- Actividad reciente
- Compartir listas
